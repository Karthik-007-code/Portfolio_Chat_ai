# Ask Karthik – Personal AI Assistant Backend

Ask Karthik is a production-conscious, lightweight AI assistant backend that powers the conversational widget on [Karthik's Portfolio](https://karthik-007-code.github.io/karthik-007-code/). It serves as Karthik's digital representative, accurately answering inquiries about his education, technical skill sets, projects, ThoughtWorks apprenticeship, and background in real time over WebSockets.

---

## 🏗️ Architecture & Key Design Decisions

- **FastAPI + WebSockets**: Provides native asynchronous real-time streaming communication directly to the React frontend.
- **In-Memory Ephemeral Sessions**: No database (PostgreSQL, Redis, MongoDB) is used. Sessions exist purely in-memory within the WebSocket connection lifecycle. Once the connection is closed, the session is purged immediately.
- **Context-Injected Knowledge Base**: Hand-maintained JSON files in `knowledge/` are merged with supplementary data scraped from public sources (`github.scraped.json`, `portfolio.scraped.json`) during application startup.
- **Provider-Agnostic LLM Client**: Utilizes `AsyncOpenAI` pointed at Groq's fast inference endpoint (`qwen/qwen3.8-27b`). Swappable to OpenAI or any OpenAI-compatible provider with zero code changes.
- **Security-First Architecture**:
  - Origin validation against configured allowed domains (`ALLOWED_ORIGINS`).
  - Sliding-window rate limiting per session (`MAX_MESSAGES_PER_MINUTE`).
  - Strict input length limits (`MAX_MESSAGE_LENGTH`) and turn capping (`MAX_CONVERSATION_TURNS`).
  - Privacy-preserving logging (message payloads and LLM outputs are never written to logs).

## 🚀 Local Development Setup

### 1. Prerequisites
- Python 3.12+
- `uv` (Fast Python package and dependency manager)

### 2. Install Dependencies
```bash
uv sync
```

### 3. Configure Environment Variables
Create a `.env` file in the project root based on `.env.example`:
```bash
cp .env.example .env
```
Update `.env` with your API key:
```ini
GROQ_API_KEY=gsk_your_actual_key_here
LLM_MODEL=qwen/qwen3.8-27b
LLM_BASE_URL=https://api.groq.com/openai/v1
LLM_TIMEOUT_SECONDS=30
ALLOWED_ORIGINS=https://karthik-007-code.github.io,http://localhost:5173,http://localhost:3000
MAX_MESSAGE_LENGTH=1000
MAX_CONVERSATION_TURNS=20
MAX_MESSAGES_PER_MINUTE=15
```

### 4. Optional: Run Public Data Ingestion
To refresh the supplementary knowledge files from GitHub and your portfolio:
```bash
uv run python scripts/ingest_knowledge.py
```

### 5. Start the Development Server
```bash
uv run uvicorn portfolio_chat_ai.main:app --host 0.0.0.0 --port 8000 --reload
```
Health check endpoint: `http://localhost:8000/health`
WebSocket endpoint: `ws://localhost:8000/ws/chat`

### 6. Run the Test Suite
```bash
uv run pytest -v
```

## 📡 WebSocket API Specification (For React Frontend)

### Connection
- **URL**: `ws://localhost:8000/ws/chat` (local) or `wss://<your-render-app>.onrender.com/ws/chat` (production)
- **Origin Header**: Must match one of `ALLOWED_ORIGINS` (browsers handle this automatically).

### 1. Connection Initialized (Backend -> Frontend)
Upon connection, the server sends a ready frame:
```json
{
  "type": "session_ready",
  "message": "Connected to Ask Karthik."
}
```

### 2. Visitor Sends Message (Frontend -> Backend)
```json
{
  "message": "What projects has Karthik built?"
}
```

### 3. Server Streams Response Tokens (Backend -> Frontend)
Tokens are pushed as they are generated:
```json
{
  "type": "chunk",
  "content": "Karthik "
}
```

### 4. Server Signals Stream Completion (Backend -> Frontend)
```json
{
  "type": "stream_end",
  "message": null
}
```

### 5. Control / Error Frames (Backend -> Frontend)
If an error occurs or a limit is hit:
```json
{
  "type": "error" | "rate_limited" | "limit_reached",
  "message": "Friendly explanation of what happened."
}
```

## ⚛️ React Integration Example

```typescript
// useAskKarthik.ts
import { useEffect, useRef, useState } from 'react';

export function useAskKarthik(wsUrl: string) {
  const ws = useRef<WebSocket | null>(null);
  const [messages, setMessages] = useState<{ role: string; content: string }[]>([]);
  const [isStreaming, setIsStreaming] = useState(false);
  const [status, setStatus] = useState<'connecting' | 'ready' | 'disconnected'>('connecting');

  useEffect(() => {
    const socket = new WebSocket(wsUrl);
    ws.current = socket;

    socket.onopen = () => setStatus('ready');
    socket.onclose = () => setStatus('disconnected');

    socket.onmessage = (event) => {
      const data = JSON.parse(event.data);

      if (data.type === 'chunk') {
        setMessages((prev) => {
          const last = prev[prev.length - 1];
          if (last && last.role === 'assistant') {
            return [...prev.slice(0, -1), { role: 'assistant', content: last.content + data.content }];
          }
          return [...prev, { role: 'assistant', content: data.content }];
        });
      } else if (data.type === 'stream_end') {
        setIsStreaming(false);
      } else if (data.type === 'rate_limited' || data.type === 'error' || data.type === 'limit_reached') {
        alert(data.message);
        setIsStreaming(false);
      }
    };

    return () => {
      socket.close();
    };
  }, [wsUrl]);

  const sendMessage = (text: string) => {
    if (!text.trim() || isStreaming || !ws.current) return;
    setMessages((prev) => [...prev, { role: 'user', content: text }]);
    setIsStreaming(true);
    ws.current.send(JSON.stringify({ message: text }));
  };

  return { messages, sendMessage, isStreaming, status };
}
```

## ☁️ Deployment Guide (Render)

When ready to deploy on **Render**:

1. **Create a New Web Service** on Render connected to this GitHub repository.
2. **Environment**: `Python 3`
3. **Build Command**:
   ```bash
   pip install uv && uv sync --frozen
   ```
4. **Start Command**:
   ```bash
   .venv/bin/uvicorn portfolio_chat_ai.main:app --host 0.0.0.0 --port $PORT
   ```
5. **Health Check Path**: `/health`
6. **Environment Variables on Render**:
   - `GROQ_API_KEY`: *(Your secret Groq API key)*
   - `LLM_MODEL`: `qwen/qwen3.8-27b`
   - `LLM_BASE_URL`: `https://api.groq.com/openai/v1`
   - `ALLOWED_ORIGINS`: `https://karthik-007-code.github.io,http://localhost:5173`
   - `PYTHON_VERSION`: `3.12.2`
